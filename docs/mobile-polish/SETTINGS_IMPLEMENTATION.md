# Approved B — Refined Categories

The user selected Settings B on November 25, 2026. The real Settings screen now uses the reviewed vertical category index with icons, descriptions and one focused section. Wide layouts place the same index alongside the content; phones retain the category list above it. The selected category has a restrained Aero highlight. Identical inner form headings are omitted when the category heading already supplies the same text; headings with different meaning remain.

All seven existing groups and all 44 current controls remain in the document with their original form IDs, input names, actions and controllers. Category selection changes only `hidden`, focus and accessible navigation state. It does not remount the forms or save a journal preference. Inactive groups are hidden from keyboard and accessibility navigation. Up/Down and Home/End use a single roving tab stop; clicking an existing category anchor reveals its panel before focus and scrolling. The profile disclosure, default-rest ownership, appearance updates, backup/import/export, notification/calendar controls and safe updater retain their original implementations.

`createSettingsNavigation()` exposes `sync()`, `select()` and `stop()`. Selection survives a save, redraw or same-document route change; a fresh page starts with Appearance. Its temporary DOM draft cache preserves unsaved fields through category changes and unrelated redraws, including checkbox groups, multiple exercise exclusions, units and the existing canonical-increment metadata. The cache restores an edit only while the newly rendered persisted baseline is unchanged. It dispatches no input events and performs no storage operations. The current 44 Settings inputs contain no file fields; import/backup file pickers live in separate dialogs outside this controller's scope.
