# Prototype typography

Manrope and DM Sans are locally served variable fonts, distributed under the SIL Open Font License 1.1. Full license notices are included beside the font files.

Sources: https://github.com/google/fonts/tree/main/ofl/manrope and https://github.com/google/fonts/tree/main/ofl/dmsans.

These review copies contain a Latin character subset, created with FontTools, compressed as WOFF. Manrope is approximately 35 KB and DM Sans 91 KB. No third-party font requests are made by the gallery. These assets are isolated documentation; the actual app's font system has not changed.
