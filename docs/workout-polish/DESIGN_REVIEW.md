# Choose one combined direction

[Open the interactive review](review/). Switch A/B/C, Charts/Focus sets/Plan creator and Light/Dark. It uses fictional data in memory, never your journal.

| Direction | Chart inspection | Completed sets | Plan creator | Tradeoff |
|---|---|---|---|---|
| **A · Inline precision — recommended** | Compact floating readout, guide and exact point | Soft green fill and check; blue current set | Self-contained cards with aligned target fields | Readout occupies a little of the plot |
| B · Field notebook | Fixed readout above the plot | Green outline and check | Open ruled exercise ledger | More chart height; less separation between exercises |
| C · Session console | Fixed readout below the plot | Minimal green completion rail and check | Exercise selector with one configuration workspace | An extra tap to compare exercise settings |

Every direction retains editable completed sets, exercise selection/reordering, all advanced plan controls and deadline-based timer controls. Plan examples use real catalog exercises; chart/session records are fictional. The isolated app retains its released Aero styling until approval. No merge is authorized.
