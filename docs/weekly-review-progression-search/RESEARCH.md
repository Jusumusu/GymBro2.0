# Evidence and implementation decisions

- ACSM, *Progression Models in Resistance Training for Healthy Adults* (2009), [PubMed / DOI](https://pubmed.ncbi.nlm.nih.gov/19204579/). Supports gradual overload based on repeated capacity, goals and training status, rather than arbitrary changes after every workout. It does not validate this app's specific algorithm. The retained 7.5% increment guard is a conservative product rule, not a scientific safety threshold. Existing all-set ceiling behavior is preserved; load-mode early increases require two recent complete same-load, same-target exposures with controlled reported effort. No new sets or exercises are applied automatically.
- Refalo et al., *Methods for Controlling and Reporting Resistance Training Proximity to Failure: Current Issues and Future Directions* (2022), [PubMed](https://pubmed.ncbi.nlm.nih.gov/35247203/). RIR is a self-report with limitations, not an objective measurement. Missing RIR remains valid; recommendations explain uncertainty. A single hard session does not diagnose fatigue, overtraining or a plateau.
- Weekly reviews use actual completed sets, exercise-specific comparisons and real goal records. Workload is not muscle growth; estimated 1RM uses existing 1–10-rep bounds. Intentional lighter/shortened sessions remain in workload totals but do not establish comparable performance changes.
- Weight comparisons use matching elapsed calendar days. Three entries spanning at least three days in each window is an explicit conservative coverage rule, not a clinical validation. No smoothing invents missing entries. A greater-than-1% change is reported neutrally rather than rewarded; the number is a product caution, not a diagnosis or recommended loss/gain rate. Tape measurements remain labeled observations.
- Search uses Unicode normalization, exact-name/alias precedence, tokens and bounded edit distance including transpositions. Short queries do not use fuzzy matching. Existing category selection clears when a user starts a global query; any filters explicitly selected during a query are honored. Favorites and recency break lexical ties only.
- Glass options preserve the approved Aero palette and typography. They show the same real rendered content with different surface fill/blur values. Full-screen and table blur are avoided. Reduced transparency and missing backdrop-filter support use opaque surfaces. Desktop Chromium rendering is useful evidence, not proof of physical-device performance.
